MODE D’EMPLOI

Le bon code est le Data Matrix

  1. Retourne la boîte.
  2. Repère le petit carré proche du code-barres.
  3. Vise-le à 8–15 cm, bien à plat.
  4. Si le grand code-barres gêne, masque-le avec ton doigt.
